# 🌐 Deepak Yogi - Premium Portfolio

A modern, responsive, and animated personal portfolio website built using **HTML, CSS, and JavaScript**. This portfolio showcases professional experience, technical skills, and projects with smooth UI interactions and elegant design.

---

## 🚀 Features

* ✨ Modern UI with glassmorphism design
* 🎯 Smooth scrolling navigation
* 🔥 Scroll reveal animations
* ⌨️ Typing animation effect
* 🧑‍💻 Professional experience section
* 🛠 Skills and project showcase
* 📱 Fully responsive (mobile-friendly)
* 🎨 Interactive hover effects

---

## 🛠 Tech Stack

* **HTML5**
* **CSS3 (Flexbox + Grid + Animations)**
* **JavaScript (Vanilla JS)**
